HRPro — DANH MỤC CÔNG NGHỆ SỬ DỤNG
====================================
Cập nhật theo package.json, Prisma schema, Docker trong repo.
Phiên bản ghi theo semver khai báo (^x.y.z = tối thiểu x.y.z).


1. TỔNG QUAN KIẾN TRÚC
----------------------
Mô hình: Client–Server, REST API, tách frontend / backend.

  Trình duyệt  →  Next.js (fontend/, cổng 3000)
                      ↓  HTTP JSON + JWT
               Express REST (backend/, cổng local 5001)
                      ↓  Prisma ORM
               MySQL 8 (utf8mb4), cổng Docker 3307


2. NGÔN NGỮ VÀ MÔI TRƯỜNG
-------------------------
- JavaScript (ES module phía frontend, CommonJS phía backend)
- Node.js  >= 18  (Docker image: node:20-alpine)
- npm
- HTML / CSS (không dùng TypeScript)


3. FRONTEND  (thư mục fontend/)
-------------------------------
Framework & UI
  Next.js          ^15.0.0     App Router, React Server/Client Components
  React            ^19.0.0
  react-dom        ^19.0.0
  CSS thuần        src/app/globals.css (giao diện gốc)
                   src/app/modern.css, overrides.css (lớp hiện đại)

Gọi API
  fetch (Web API)  src/api/client.js
  JWT lưu localStorage, header Authorization: Bearer <token>

Kiểm thử
  Vitest           ^2.1.0      npm test  =  vitest run
                               file: src/**/*.test.js  (hàm thuần *Utils.js)

Chạy
  next dev         http://localhost:3000
  Biến môi trường  NEXT_PUBLIC_API_URL  (mặc định http://localhost:5001/api)

5. CƠ SỞ DỮ LIỆU (Prisma / MySQL)
---------------------------------
Bảng: users, employees, departments, shifts, employee_shifts,
      attendance, tasks, kpis, payrolls, payroll_settings, salary_locks

Enum: Role, EmployeeStatus, AttendanceStatus, AttendanceType, TaskStatus

ORM: Prisma Client — truy vấn typed, migrate trong backend/prisma/migrations/


6. TRIỂN KHAI / HẠ TẦNG
-----------------------
- Docker            image MySQL 8.0, backend node:20-alpine
- Docker Compose    3.9     docker-compose.yml
                    hrpro-mysql   host 3307 → container 3306
                    hrpro-backend host 5000 (Docker) / local PORT=5001
- Git / GitHub      https://github.com/MinhNgyen/Phat-trien-ung-dung-web-quan-ly-nhan-su-HRPro
